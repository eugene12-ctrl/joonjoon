# 달이네 숲 (목업)

> 달이 관리 탭에서 "달이네 숲"을 눌렀을 때 덮이는 화면의 정적 목업입니다. 아직 데이터나 동작은 없습니다.

- 담당자: (미정)
- 하는 일 (한두 문장): 임직원이 걸어서 나무를 심어 온 "유진의 숲"을, 고객의 산책(달이랑 산책)과 이어 소개합니다. 달이가 유진을 광고하지 않고, 내 나무가 자라는 이야기 안에서 숲의 역사를 세 줄로만 보여 줍니다.
- 화면 구성 요소:
  1. 내 나무 히어로: 산책 횟수, 숲 %, 씨앗→새싹→묘목→나무 단계, 언덕 위 내 나무
  2. 모두의 숲 게이지: 임직원 걸음 + 고객 걸음(올해 처음), 모인 걸음과 심을 나무 수
  3. 이 숲이 시작된 이야기: 연도와 사실 세 줄, 기사 보기 링크
  4. 내 나무가 심어지면: 이름 팻말, 봄 심는 날 초대, 자라는 사진. "심는 날 소식 받기" 버튼
  5. 숲 소식: 내 나무와 모두의 숲 타임라인
- 사용자 동작 (누르기, 입력 등): 기사 보기(달이 안에서 읽기), 심는 날 소식 받기. 목업이라 아직 동작 없음
- 사용하는 가상 데이터: 내 나무 단계, 산책 횟수, 고객 걸음, 이번 시즌 숫자는 모두 가상. 숲의 역사 세 줄(2014, 2023, 2026년 봄)은 유진에버 공개 기사 기준 (`docs/research-eugene-ever.md`)
- 진입 경로: 달이 > 관리 > 달이 키우기 > 달이네 숲 (또는 관리 탭의 "달이랑 산책" 완료 뒤 한 줄)

## 실제 화면으로 옮길 때

- `features/dali/dali.js`의 `growPage()` 안 "달이네 숲" 카드를 누르면 이 화면이 `.dali-page`로 덮이게 합니다.
- 산책 미션(`DALI_MISSIONS`의 `m-walk`)이 `state.forest`를 10씩 올리므로, 단계는 forest 값으로 나눕니다 (0~24 씨앗, 25~49 새싹, 50~99 묘목, 100 나무).
- 「시연용 가상 화면」 표시는 화면 안이 아니라 발표자 상자에 둡니다 (CLAUDE.md).
