# 관심종목 · 차트 · 주문 · 잔고 (MTS 화면 재현)

> 시연용 가상 화면입니다. 계좌는 모의 번호, 이름은 홍길동, 종목은 가상종목이고 숫자는 모두 자리표시입니다.
> 기준: 화면 녹화 영상(실명·계좌번호를 가린 프레임). 영상 원본은 커밋하지 않습니다(`.gitignore`).

- 담당자:
- 하는 일: 기존 MTS의 관심종목, 차트, 주문, 계좌/잔고 화면을 그대로 재현하고, 화면 위에 수달 비서 달이(features/dali)를 띄웁니다.
- 진입 경로: 전체메뉴 > 국내주식 > 관심종목 / 주문 / 차트 / 잔고 타일 (`src/js/config.js`의 `TILE_LINKS`)
- 주소: `features/mts/index.html#watch` · `#chart` · `#order` · `#balance` (`#balance/<탭이름>`으로 특정 탭)

## 파일

| 파일 | 역할 |
|---|---|
| `js/data.js` | **가상 데이터.** 계좌, 종목, 관심그룹, 지수 띠, 뉴스 띠, 호가 |
| `js/common.js` | 숫자 표시(`num`, `rate`), 아이콘, 화면 틀(헤더·청록 탭·하단 메뉴·지수 띠), 팝업, 토스트 |
| `js/screens/watch.js` | 관심종목 (보유/최근/관심1), 종목상위, 유진조회상위, 쏙쏙섹터(서비스 신청 안내) |
| `js/screens/chart.js` | 차트 (일/주/월/분/틱, 이동평균 4개, 거래량) |
| `js/screens/order.js` | 주문 (계좌 비밀번호 키패드 → 호가 + 주문 입력 → 안내/주문확인 → 증거금 부족) |
| `js/screens/balance.js` | 계좌/잔고 13개 탭 |

## 숫자 채우기

`js/data.js`에서 `null`인 자리에 숫자를 넣으면 자리표시 대신 그 숫자가 나옵니다. (`price`, `change`, `rate`, `volume`, `ORDER_BOOK` 등)
숫자를 넣으면 시연 규칙에 따라 화면에 가상 데이터임을 계속 표시합니다 (맨 위 띠 문구).
차트 캔들 모양은 `chart.js`의 `PERIODS` 씨앗값으로 만든 가상 흐름입니다.
