# 시장 소식 (공시 · 뉴스)

- 담당자:
- 하는 일: 캐릭터가 오늘의 공시(OpenDART)와 시장 뉴스(네이버 검색)를 물어다 보여 줍니다. 원문 링크로 이어지며, 투자 권유 문구는 넣지 않습니다.
- 화면 구성 요소: 시연용 가상 화면 띠, 캐릭터 말풍선, 공시/뉴스 탭, 목록, 출처·안내 문구
- 사용자 동작: 탭 바꾸기, 새로고침, 항목 눌러 원문 보기
- 사용하는 데이터: Supabase `disclosures`, `news` 테이블. 연결 정보가 없거나 실패하면 `mock-feed.js` 가상 데이터
- 진입 경로: 지금은 `features/feed/index.html`을 직접 엽니다. 전체메뉴 연결은 추후
- 구축 방법: [docs/supabase-setup.md](../../docs/supabase-setup.md)
