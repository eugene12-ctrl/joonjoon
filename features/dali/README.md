# 달이 (화면 우측 하단의 AI 비서)

- 담당자: 팀 준준
- 하는 일: 유진투자증권과 유진투자선물 앱의 모든 화면 우측 하단에 떠 있는 아기 해달 비서. 그 앱의 관심종목과 보유 종목을 자동으로 추적해 등락과 뉴스를 보여 주고, 의미 있는 뉴스가 나오면 느낌표로 알린다. 거래하면 살 때와 팔 때의 뉴스, 분위기를 매매일지에 알아서 적고, 미션과 콘텐츠로 해달을 키운다.
- 화면 구성 요소: 플로팅 달이(느낌표, 말풍선), 달이 시트(뉴스, 매매일지, 관리), 뉴스 읽기 화면, 주문 화면, 유진투자선물 시연 화면, 발표자용 시연 버튼
- 사용자 동작: 달이 누르기, 뉴스 읽기, 뉴스 헤더의 종목 이름을 눌러 바로 주문, 매매일지 메모(선택), 담당 PB 공유(선택), 미션과 퀴즈
- 사용하는 가상 데이터: `features/dali/dali-data.js` (서버 없이 파일을 바로 열 수 있게 JS로 둠)
- 실제 데이터: 종목 화면의 뉴스 탭은 실제 토스증권 뉴스(`dali-feed.js`가 Supabase `news` 테이블을 읽음, 같은 4개 회사, 최근 2주)를 보여 주고, 누르면 달이 안에서 본문을 읽는다 (밖으로 내보내지 않음). 공시 탭은 실제 DART 공시를 보여 준다 (`dali-feed.js`가 Supabase `disclosures` 테이블을 읽음. 삼성전자, SK하이닉스, 현대차, NAVER만 최근 1년 중 최신 20건). 공시명을 "배당 안내" 같은 쉬운 제목으로 바꾸고 원래 공시명을 한 줄로 단다. 테이블에 `summary` 열이 생기면 그 한 줄 요약을 대신 쓴다. 불러오지 못하면 안내만 띄우고 공시를 지어내지 않는다.
- 진입 경로: 화면 우측 하단 달이, 또는 전체메뉴 > 쏙쏙클럽 > 신규 기능

## 지키는 원칙

- 증권 앱에선 주식만, 선물 앱에선 선물만 다룬다. 달이와 조약돌은 같다.
- 종목명은 실제지만 시세, 뉴스, 매매, 손익은 모두 가상이다. 실제 회사의 공시나 실적은 지어내지 않고 시장 흐름 수준의 뉴스만 쓴다.
- 느낌표는 공시, 실적, 큰 변동일 때만. 먼저 말을 거는 건 하루 한 번까지.
- 매매일지는 달이가 알아서 쓴다. 메모는 선택이다. 손실 직후에 이유를 묻지 않는다.
- 조약돌은 읽기, 돌아보기, 배우기에만 준다. 거래로는 주지 않는다.
- 종목 추천, 매매 시점 제시를 하지 않는다.

## 유진다움

- 증권 앱과 선물 앱에서 같은 달이, 같은 조약돌
- 선물 종목의 밤 뉴스, 유진 리서치 한 줄 요약
- 원하면 담당 PB에게 매매일지 공유 (리테일 영업 현장과 연결)
- 관리 탭의 가치걸음 시즌, 서울오픈 예측 퀴즈, 유진의 숲 공동 게이지

## 시연 순서

1. 처음 열면 달이 인사 팝업이 뜬다 (`dali-intro.js`, 한 번만. 발표자 버튼 "첫 인사 다시 보기"나 "처음으로"로 다시 볼 수 있음). 닫으면 카드가 오른쪽 아래 달이 자리로 들어가고, 달이가 인사하며 느낌표가 켜져 있다.
2. 달이를 누르면 뉴스 탭. 자동 추적 중인 종목과 등락, "AI 요약" 한 줄.
3. 느낌표 뉴스(SK하이닉스)를 눌러 읽고, 헤더의 종목 이름을 누르면 바로 주문창.
4. 매수 주문 → 매매일지에 살 때 상황이 자동으로 적힌다. 삼성전자 카드에서 손익, 살 때와 팔 때, 메모를 본다.
5. 발표자 버튼으로 유진투자선물 전환 → 선물 종목만 보인다 → 의미 있는 뉴스 도착.
6. 관리 탭에서 해달 성장, 증거금 퀴즈, 가치걸음과 서울오픈, 유진의 숲.
   - 달이네 바다: 미션을 하면 조약돌이 날아와 안기고, 단계가 오르면 "달이가 자랐어요!"가 뜬다. 달이를 누르면 하트가 나온다.
   - 성장 단계는 아기, 헤엄치는, 조개 여는, 꾸준한 달이 4단계(조약돌 0, 8, 11, 14개). 시작 7개에 미션 합계 8개라 시연 중에 끝까지 볼 수 있다.
   - 옷장: 빨간 리본, 바다 꽃, 뉴스 안경, 학사모. 단계가 오르면 하나씩 열린다.
   - 발표자 버튼 "조약돌 3개 주기"로 성장 장면을 빠르게 보여 줄 수 있다.
   - 조개 여는 달이(조약돌 11개)가 되면 "한 달 습관 리포트" 줄의 "열기"가 생기고, 누르면 10월 리포트 화면(큰 숫자와 넉넉한 여백, 색은 앱 머리와 같은 청록)(`dali-report.js`, `dali-report.css`)이 열린다. 숫자 타일 셋, 읽은 날과 산 날 달력, 한 종목 비중 막대, 달이가 본 것 세 줄. 매매 날짜는 `dali-customer.js`의 10월 매매에서 가져오고 읽은 날과 비중은 가상 숫자다. 평가하지 않고 관찰만 적는다.
   - 헤엄치는 달이(조약돌 8개)가 되면 "주간 돌아보기 카드" 줄의 "열기"가 생기고, 누르면 이번 주(10월 26일~30일) 화면(`dali-week.js`, `dali-week.css`)이 열린다. 리포트와 같은 옷(.dr 스타일)을 입고, 제목 문장 하나, 숫자 타일 셋(사고판 날, 리포트 읽음, 급등일 매수), 한 주 달력 한 줄(판 날은 테두리), 이번 주 한 일 목록, 지난주와 숫자만 나란히. 매매는 `dali-customer.js`의 이번 주 매매와 어제 걸어 둔 현대차 체결에서 가져온다.
