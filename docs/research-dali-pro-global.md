## 9. 달이에 가져올 것 / 피할 것

**가져올 것**
- Robinhood 포트폴리오 Digest의 3섹션(시장 배경 / 수익 기여 / 상위 변동)과 "보유 종목 예정 이벤트" 블록. 홈 화면 상시 노출, 뉴스 발생 시 재생성.
- Schwab의 "전일 종가 대비 요약 + 가장 많이 움직인 보유 종목 5개". 범위를 좁혀 정확도를 지키는 설계.
- eToro Tori의 "가장 관련 있는 시점에 띄우기".
- Zerodha의 집중도 50% 기준과 Dhan의 과매매 카운터처럼 숫자 기준이 분명한 습관 피드백.

**피할 것**
- 채팅 입력창을 첫 화면에 두는 것. Cortex Assistant, Moomoo AI, Ask IBKR 모두 질문형이고 우리 차별점은 질문 없이 완성된 화면.
- 배지, 포인트, 거래 횟수 보상. OSC와 JBEF 실험 모두 거래와 위험 감수를 키움.
- 포트폴리오 전체를 자유 서술로 요약하는 것. Trading 212처럼 범위가 넓을수록 오류가 눈에 띔. 데이터로 검증 가능한 숫자 위주, 생성 문장은 짧게.
