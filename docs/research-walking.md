# 유진 걷기 캠페인 분석

유진은 2026년에 걷기 캠페인을 두 번 했습니다. 달이의 "유진다움"과 "그룹 확장성"을 증명하는 가장 강한 재료입니다.

## 1. 사실 정리

| 항목 | ① 유진이랑 함께 걸어 봄 | ② 유진이랑 가치걸음 |
|---|---|---|
| 주최 | 유진투자증권 | 유진그룹 |
| 대상 | 증권 임직원 (사내) | **일반 고객 + 5개 계열사 임직원** (유진기업, 유진투자증권, 동양, 유진홈센터, 유진로지스틱스) |
| 기간 | 2026-04-20 ~ 05-17 (약 4주) | 2026-10-01 ~ 10-31 (한 달) |
| 공동 목표 | 누적 1억 보 | 누적 3억 걸음 |
| 결과·약속 | **600여 명이 1억 1,561만 보** (목표 초과) → 노을공원에 **나무 400그루** 기증 | 3억 걸음 달성 시 자립준비청년에게 **1,000만 원** 기부 |
| 목적 | 기후위기 대응(환경보호), 임직원 건강 | 자립준비청년 지원, 참여형 사회공헌 |
| 참여 방법 | 기사에 앱 언급 없음 | **외부 걷기 기부 앱 '빅워크'** 설치 → 회원가입 → 캠페인 선택 |
| 개인 보상 | - | 개인별 기부 인증서 |
| 이벤트 | - | 1만 걸음 이상 + 빅워크 기부 → 인증서를 해시태그와 함께 개인 SNS에 게시 → 유진그룹 인스타그램 팔로우 → 이벤트 게시물에 링크 댓글 → 추첨(가민 스마트워치, 온러닝 운동화, 샥즈 이어폰), 11/9 발표 |
| 사내 연계 | - | 그룹 사보 '유진에버' 사내 이벤트, 러닝 경품 |

## 2. 이 캠페인이 증명하는 것

1. **유진은 이미 "일상 습관 → 모두의 목표 → 사회적 가치" 구조를 운영하고 있다.** 달이의 핵심 루프와 같은 구조다. 우리가 새로운 걸 하자는 게 아니다.
2. **사람들이 실제로 참여한다.** 증권 임직원 600여 명이 목표를 넘겼다.
3. **돈이 아닌 보상으로도 움직인다.** 나무, 기부, 인증서, 추첨 경품. 앤트 포레스트 연구(경제적 보상보다 가치·사회적 동기가 지속에 유의미)와 같은 결론이다.
4. **그룹이 반복할 의지가 있다.** 상반기 증권 사내 → 하반기 그룹 전체·일반 고객으로 커졌다. 확장 방향까지 달이 로드맵(계열사 → 그룹)과 같다.

## 3. 빈틈 = 달이가 채울 자리

| 빈틈 | 지금 | 달이가 있으면 |
|---|---|---|
| **고객이 머무는 곳이 유진 밖** | 고객은 외부 앱 '빅워크'에서 걷고, 인스타그램에서 인증한다. 참여 경험과 관계가 유진에 남지 않는다 | 유진 앱 안에서 걷고, 모으고, 확인한다 |
| **한 달 뒤 끝난다** | 캠페인이 끝나면 고객이 돌아올 이유도 끝난다 | 시즌이 끝나도 달이는 남는다. 다음 시즌으로 이어진다 |
| **참여가 번거롭다** | 앱 설치 → 가입 → 걷기 → 인증서 → SNS 게시 → 팔로우 → 댓글. 7단계 | 앱을 열면 달이가 오늘 걸음과 조약돌을 보여 준다 |
| **금융과 연결이 없다** | 증권이 주최한 걷기도 증권 앱·증권 고객과는 무관했다 | 증권·선물 MTS 안에서 일어난다 |
| **계열사별로 따로** | 증권 캠페인, 그룹 캠페인이 따로 | 같은 달이, 같은 조약돌로 계열사가 이어진다 |

## 4. 달이에 넣는 방법: '가치걸음 시즌'

- **모두의 목표 게이지:** "유진 고객 모두의 조약돌이 ○○개 모이면 유진의 숲에 나무 한 그루." 개인 보상 대신 공동 목표로 사회적 동기를 만든다.
- **걸음도 습관이다:** 시즌 동안 하루 걸음 목표를 채우면 조약돌 하나. 앎 미션(브리핑·퀴즈)과 함께 쓴다.
- **인증서를 앱 안에서:** 시즌을 마치면 달이가 개인 기부 인증서를 준다. 공유는 선택이다.
- **계열사 미션:** 그룹 시즌 동안 계열사 미션을 넣는다 (예: 홈센터 "오늘의 DIY 상식").
- **주의:** 걸음 수는 건강 데이터라 휴대폰 건강 앱 연동 동의가 필요하다. 시연에서는 가상 걸음 수를 쓴다.

## 5. 발표 문장 후보

> *"유진은 이미 고객과 함께 걷고 있습니다. 올해만 두 번, 1억 보를 넘겨 나무 400그루를 심었습니다. 그런데 그 길은 유진 앱 밖, 다른 회사 앱 위에 있습니다. 그리고 한 달이 지나면 끝납니다. 달이는 그 길을 유진 앱 안으로 가져와서, 끝나지 않게 만듭니다."*
