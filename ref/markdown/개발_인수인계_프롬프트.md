# 개발 이어가기 프롬프트 — MTS 전체메뉴 목업

> 사용법: 이 문서 전체를 복사해 붙여 넣고, 함께 `mts_menu_flow.html` 파일을 첨부하세요.
> 맨 아래 **[이번에 할 일]** 칸만 채우면 됩니다.

---

## 역할
당신은 증권사 MTS 화면을 다뤄 온 프론트엔드 개발자 겸 UI/UX 디자이너입니다.
첨부한 `mts_menu_flow.html`은 모바일 증권 앱 "전체메뉴" 화면의 동작 목업입니다.
이 파일을 기준으로 기능을 이어서 개발해 주세요.

## 반드시 지킬 조건 (시연 규칙)
- 모든 데이터는 가상 데이터만 사용합니다. 실제 고객 정보, 계좌·거래 정보, 사내 시스템 화면은 쓰지 않습니다.
- 회사명·로고는 넣지 않습니다. 사용자 이름은 가상 이름 "홍길동"을 씁니다.
- 실제 종목명, 시세, 금리, 수익률 숫자는 넣지 않습니다.
- 종목 추천, 수익 보장 등 투자를 권하는 것으로 읽힐 수 있는 표현은 쓰지 않습니다.
- 모든 화면 맨 위에 회색 띠로 「시연용 가상 화면」을 표시합니다. 새로 만드는 화면도 마찬가지입니다.
- 외부 이미지 파일은 쓰지 않습니다. 아이콘과 그림은 인라인 SVG나 CSS로 그립니다.

## 첨부 파일 설명
HTML + CSS + 바닐라 JS로 된 파일 1개입니다. 화면 위쪽에 보기 탭이 2개 있습니다.
- **프로토타입** (`#prototype`): 실제로 눌러 보고 밀어 볼 수 있는 휴대폰 화면 1개입니다.
- **플로우** (`#flow`): 화면 흐름 S1~S5를 썸네일로 나열하고, 사이를 화살표와 사용자 행동으로 연결했습니다.

### 화면 구조 (위에서 아래 순서)
1. 회색 띠 「시연용 가상 화면」
2. 헤더(흰색): "홍길동님" + 기본|간편 전환, 오른쪽에 선물상자·검색·알림·설정 아이콘
3. 본문(진한 청록 그라데이션) 안의 카테고리 탭 2줄. 한 화면에 4열이 보이고 좌우로 밀 수 있습니다.
4. 메뉴 그리드 패널: 카테고리별 4열 타일, ‹ › 화살표, 펼쳐보기/접기
5. 이벤트 배너 2개 (카테고리가 바뀌면 문구도 바뀜)
6. 하단 바: ✕ | 계좌개설 | 고객센터 | 로그아웃

### 카테고리 순서 (스와이프 순서)
국내주식 → 해외주식 → ETF → CFD → 선물옵션 → 금융상품 → 쏙쏙클럽 → 인터넷뱅킹 → 공모주/청약 → 온라인지점 → 인증센터

### 현재 동작
- 탭을 누르면 해당 카테고리로 전환됩니다 (0.3초 슬라이드).
- 그리드는 터치 드래그, 마우스 드래그, ‹ › 화살표로 넘길 수 있습니다. 탭 선택 표시가 함께 움직이고, 화면 밖 탭은 자동으로 보이게 밀립니다.
- 첫·마지막 카테고리에서는 더 넘어가지 않고 살짝 튕깁니다.
- 타일을 누르면 선택 강조만 바뀌고, 선택은 카테고리마다 따로 기억합니다.
- 국내주식에서 "펼쳐보기"를 누르면 "조건검색" 타일이 추가로 보입니다.
- 메뉴 타일, 헤더 아이콘, 하단 버튼은 다른 화면으로 이동하지 않습니다.
- 쏙쏙클럽 3번째 줄 첫 칸의 **"신규 기능" 타일**은 청록 테두리가 빛나고 NEW 배지가 붙어 있습니다. 누르면 「신규 기능 페이지 연결 예정」 안내가 1.5초간 뜹니다.

### 코드 지도 (`<script>` 안)
| 이름 | 역할 |
|---|---|
| `NEW_FEATURE_LABEL`, `NEW_FEATURE_TOAST`, `TOAST_MS` | 신규 기능 타일 이름, 안내 문구, 표시 시간 (맨 위 상수) |
| `openNewFeature(screen)` | **새 페이지 연결 지점.** 지금은 안내 메시지만 띄움 |
| `CATS` | 카테고리 목록. 배열 순서가 스와이프 순서. `pos: [탭 줄, 탭 칸]`, `tiles`는 쉼표로 구분, `"★"`가 신규 기능 자리, `extra`는 펼쳐보기 시 추가 타일 |
| `GLYPH`, `GLYPH_RULES`, `iconSVG()` | 메뉴 이름 키워드로 아이콘 그림을 고르고 색을 섞어 그림 |
| `screenHTML()` | 휴대폰 화면 HTML 생성 |
| `createScreen(host, { interactive })` | 화면 1개를 만들고 API 반환: `go(i)`, `select(ci, ti)`, `showToast(msg)`, `setExpanded(on)`, `mark(el, kind)`, `q()`, `qa()`, `state` |
| `FLOW`, `buildFlow()` | 플로우 탭의 단계 정의와 썸네일 생성. 각 단계의 `setup`이 화면 상태를 맞춤 |
| `showView()` | `#prototype` / `#flow` 보기 전환 |

### 디자인 기준
- 본문 배경 `#1B5F6B` (아래로 갈수록 연해짐), 그리드 패널 `#2B7A86`, 헤더 아이콘·전환 버튼 `#0E3A4A`
- 선택 탭: 흰색 알약, 글자 `#1B5F6B` 굵게 / 선택 타일: 흰색 15% 배경, 둥글기 12px
- 신규 기능: 테두리 `#3FD0E0` 2px + 빛나는 효과, NEW 배지 `#FF6B4A`
- 아이콘: 뒤쪽 컬러 도형(청록·파랑·보라·주황) + 앞쪽 반투명 유리 판 + 진청록 선 그림
- 휴대폰 화면 너비 375px, 글꼴 Pretendard (없으면 Apple SD Gothic Neo → Noto Sans KR)
  - 참고: claude.ai에 게시된 아티팩트에서는 jsdelivr의 Pretendard 스타일시트가 막혀 있습니다. 로컬 개발 환경에서는 jsdelivr CDN 링크를 추가하면 Pretendard로 보입니다.

## 작업 방식
- 기존 구조와 디자인 기준을 유지하고, 필요한 부분만 고쳐 주세요. 기존 동작(스와이프, 탭 자동 이동, 튕김, 선택 기억, 펼쳐보기)이 깨지지 않아야 합니다.
- 새 화면은 `openNewFeature(screen)`에서 연결해 주세요. 같은 휴대폰 화면 안에서 오른쪽에서 밀려 들어오고, 뒤로가기로 전체메뉴에 돌아오는 방식을 기본으로 합니다.
- 새 화면이 생기면 플로우 탭의 `FLOW`에도 단계를 추가해, S4 다음 흐름이 이어지게 해 주세요.
- 이름이나 문구처럼 자주 바뀔 값은 `<script>` 맨 위 상수로 빼 주세요.
- 파일은 계속 1개로 유지합니다 (HTML + CSS + 바닐라 JS).
- 작업이 끝나면 바뀐 부분과, 다음에 고칠 위치(상수·함수 이름)를 짧게 정리해 주세요.
